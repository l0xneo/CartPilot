# Cart Pilot

Cart drives itself to wherever you tell it.

- F - to you
- G - to extraction, opens it, drives in
- H - back to the truck
- V - opens extraction, stays outside

Keys and speeds can be changed in `BepInEx/config/neo.cartpilot.cfg`.

Logs go to `BepInEx/CartPilotLogs` - send one if something breaks.
